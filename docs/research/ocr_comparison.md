# OCR 엔진 조사 및 선택 결과

## 조사 목적
본 기말 팀 프로젝트에서 사용할 OCR 엔진을 선정하기 위해
네이버 OCR과 Google Vision OCR을 비교 조사하고,
프로젝트 규모와 요구사항에 적합한 엔진을 결정한다.

## 비교 대상
- 네이버 OCR
- Google Vision OCR

## 조사 기준
- 한국어 텍스트 인식 정확도
- 약 봉투와 같은 비정형 문서 인식 안정성
- API 연동 편의성
- 비용 구조 및 과제 규모 적합성

## 조사 결과 요약

### 네이버 OCR
- 상용 서비스 중심의 과금 구조
- 한국어 인식 정확도는 우수하나,
  반복적인 테스트 및 실험이 필요한 기말 팀 프로젝트 환경에서는
  비용 부담이 발생할 수 있음
- 실제 구현보다는 비교 조사 대상으로 적합하다고 판단

### Google Vision OCR
- 한국어 인식 정확도가 높고 안정적
- 표 및 문단 구조 인식이 비교적 우수
- REST API 기반으로 FastAPI 연동이 용이함
- 무료 크레딧 및 소량 무료 사용 구간 제공으로
  기말 팀 프로젝트 및 소규모 과제 수준에서
  비용 부담 없이 테스트 및 적용 가능

## 결론
위 조사 결과를 바탕으로,
본 프로젝트에서는 Google Vision OCR을 단일 OCR 엔진으로 채택한다.

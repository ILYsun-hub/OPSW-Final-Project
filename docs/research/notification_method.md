# 보호자 알림 발송 방식 조사 및 선택

## 조사 목적
보호자 알림 기능 구현을 위해
백엔드에서 사용할 알림 발송 방식을 비교 조사하고,
프로젝트 요구사항에 가장 적합한 방식을 선정한다.

## 비교 대상
- Firebase Cloud Messaging (FCM)
- Python Scheduler 기반 알림
- 배치 작업(Cron, 주기 실행)

## 조사 기준
- 실시간 알림 가능 여부
- 구현 복잡도
- 확장성
- 서버 리소스 부담
- 모바일 앱 연동 적합성

## 조사 결과 요약

### Firebase Cloud Messaging (FCM)
- 모바일 앱 푸시 알림에 최적화된 구조
- 실시간 알림 발송 가능
- Firebase Auth 및 Firestore와 연동 용이
- 사용자 디바이스 단위 알림 관리 가능
- 보호자 알림 기능에 가장 직관적이고 안정적

### Python Scheduler
- 특정 시간 또는 주기 작업에 적합
- 서버가 항상 실행 중이어야 함
- 실시간성 확보에는 추가 로직 필요
- 알림 발송보다는 보조적인 작업에 적합

### 배치 작업 (Cron 등)
- 주기적 처리에는 적합
- 실시간 알림 구현에는 부적합
- 알림 지연 가능성 존재

## 결론
보호자에게 즉시 알림을 전달해야 하는
본 프로젝트의 특성을 고려하여,
알림 발송 방식으로 Firebase Cloud Messaging(FCM)을 채택한다.

Python Scheduler 및 배치 작업은
주간 리포트 생성 등 비실시간 처리 용도로 활용 가능하다고 판단한다.

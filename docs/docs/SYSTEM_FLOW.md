# 전체 ]기능 플로우 문서 (System Flow Documentation)

---

## 1. 문서 목적

본 문서는 프로젝트의 전체 기능 흐름을 시각적으로 정리하여 다음 목적을 달성하기 위해 작성되었다.

- 신규 팀원의 빠른 시스템 이해
- 개발 및 테스트 기준 명확화
- 기능 간 데이터 흐름 및 책임 분리 명확화

---

## 2. 전체 시스템 개요

본 시스템은 다음과 같은 흐름으로 동작한다.

- Flutter 앱을 통해 간병인이 시니어를 관리
- OCR + AI를 활용하여 처방 정보를 자동 구조화
- Firestore + Cloud Functions 기반으로 복약 스케줄 및 알림 관리
- 복약 이력과 컨디션을 기반으로 AI 분석 및 리포트 제공

---
